FAQ

Is this safe?

You control the remote session. Use Chrome Remote Desktop or Parsec — tools you choose and can end anytime. Don’t share passwords in chat; type them yourself on your machine if needed. I won’t ask for banking logins.

Do you come to my house?

No. This service is remote only. That keeps cost down and scheduling simple.

What if you can’t fix it?

If I can’t make meaningful progress in the paid window, I’ll say so plainly. For a quick-fix ($25), if we agreed on a specific outcome and it isn’t reachable remotely, we’ll talk options (refund of that fee or convert to a timed session) before continuing.

Mac / phone / console?

Primary focus is Windows PCs. Light Mac help case-by-case. Phones and game consoles are usually out of scope for this page.
