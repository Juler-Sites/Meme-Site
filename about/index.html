About

I'm Julian Robbins. I run a one-person shop in Little Rock. Most of the work is hands-on break-fix: Windows troubleshooting, hardware swaps, and pulling data off failing drives.

I also work on obsolete systems when I can get them running again. That has included AT&T U-verse and Microsoft Mediaroom gear, Dish receivers, Comcast RDK boxes, MIPS firmware, and older operating systems on newer hardware.

Things I've built

Remote PC Help

My remote Windows support service. Prices and how to reach me are on the Remote PC Help page.

L5

A custom Discord bot I built, with its own control panel.

CAUHF

A scanner and weather stream I run.

Win10MenuBridge

Puts the Windows 10 tray and taskbar right-click menus back on Windows 11, as plain Win32 popups. Code: julerobb1/win10-menu-bridge.

Uverse

A historical archive of Microsoft Mediaroom taken from a dead U-verse box. julerobb1/Uverse.

Processor-Emulator

A firmware emulator and analysis toolkit for set-top boxes and embedded systems. It can run ARM, MIPS, and x86 code, and includes work on AT&T U-verse/Mediaroom, RDK, and DirecTV firmware, plus firmware unpacking. julerobb1/Processor-Emulator.

davefs

A read-only library and CLI for Echostar/Dish DaveSystemDisk (E*FS) partitions. It opens a disk image, lists substores, and can hexdump bytes. julerobb1/davefs.

FeedFetcher

Downloads, combines, and transcribes audio feeds. It can trim silence, and it uses PocketSphinx or Whisper depending on the machine. julerobb1/FeedFetcher.

AT&T Long Lines and Bell Labs

An independent historical site about AT&T Long Lines and Bell Telephone Laboratories, at belllaboratories.net. It is not affiliated with AT&T or Nokia Bell Labs. Source: julerobb1/-belllabs.
