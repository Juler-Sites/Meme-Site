L5 Coax Privacy Policy

Public copy for Discord application listing. Operator LAN control panel is separate.

Effective: 2026-09-24 · Operator: Julian (Lightsnipe) · App: L5 Coax (Discord application)

This policy describes how the L5 Coax Discord bot (“the Bot”) handles information. The Bot is a private, owner-operated companion for a small set of Discord servers, not a public SaaS product.

What we collect

  • Discord identifiers the Bot needs to operate: guild IDs, channel IDs, user IDs, display names/nicks, roles, and message content the Bot is permitted to read (for chat replies, moderation/shield logic, and owner-configured features).
  • Operational logs on the operator’s private LAN host (for example connection health, errors, and control-panel access logs). These stay on private infrastructure.
  • Owner-configured preferences such as per-guild nick/avatar settings stored in local config on the operator’s server.

What we do not do

  • We do not sell personal data.
  • We do not use Discord content for advertising.
  • We do not intentionally share message content with third parties except as required to run the Bot’s AI reply path on infrastructure the operator controls (for example a local language-model server on the LAN), or when Discord itself is the service delivering the message.
  • We do not require end users to create a separate L5 account.

AI / model processing

When chat features are enabled, message text the Bot is allowed to see may be sent to a language-model endpoint configured by the operator (typically a local server). That processing is for generating replies only. Model providers outside the operator’s LAN are not used unless the operator explicitly changes that configuration.

DMs

If Direct Messages to the Bot are enabled, DM content is treated like other chat content the Bot processes and may be retained briefly in short-term memory/logs on the operator’s server for continuity and debugging.

Data retention

Operational logs and short-term chat memory are retained only as long as needed for operation and troubleshooting, then rotated or deleted by the operator. Guild look preferences persist until the operator clears them.

Your choices

  • Server admins can kick/remove the Bot at any time.
  • Users can avoid DMing the Bot and can ask a server admin to restrict the Bot’s channel permissions.
  • To request deletion of Bot-side stored preferences or logs that reference you, contact the operator via the Discord server where the Bot is present (owner: Julian / Lightsnipe).

Children

The Bot is not directed at children under 13. Do not use the Bot if you are under 13.

Changes

Material changes to this policy will be reflected by updating this page and the “Effective” date above.

Contact
